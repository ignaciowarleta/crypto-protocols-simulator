# Crypto Protocols Simulator

Simulador en Python de protocolos utilizados en criptomonedas y sistemas
blockchain, diseñado con fines educativos y experimentales.

------------------------------------------------------------------------

## Descripción

Crypto Protocols Simulator es un proyecto que permite explorar de forma
práctica cómo funcionan los mecanismos fundamentales detrás de las
criptomonedas.

En lugar de centrarse solo en teoría, este repositorio implementa
versiones simplificadas de distintos protocolos para facilitar su
comprensión y experimentación.

------------------------------------------------------------------------

## Contenido

El proyecto cubre conceptos clave como:

-   Estructura de blockchain
-   Funciones hash y criptografía básica
-   Transacciones
-   Bloques y validación
-   Simulación de protocolos

------------------------------------------------------------------------

## Objetivos

-   Entender cómo funcionan los sistemas descentralizados
-   Implementar protocolos desde cero
-   Simular comportamientos reales de blockchain
-   Servir como herramienta educativa

------------------------------------------------------------------------

## Tecnologías

-   Python 3
-   Algoritmos de hashing (por ejemplo, SHA-256)
-   Estructuras de datos personalizadas

## Instalación

git clone
https://github.com/ignaciowarleta/crypto-protocols-simulator.git\
cd crypto-protocols-simulator\
pip install -r requirements.txt

------------------------------------------------------------------------

## Uso

python main.py

También se pueden ejecutar módulos individuales dentro de `src/` o
ejemplos en `examples/`.
